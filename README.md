## ✨ Features

- **🎯 3D Interactive Hero** — Three.js animated 3D torus knot with gold particles and parallax mouse tracking
- **🌐 Bilingual** — Full English & Arabic support with RTL layout switching
- **🏛️ Menu System** — Filterable menu with categories (Appetizers, Mains, Desserts, Beverages)
- **👨‍🍳 Chef Spotlight** — Chef Ahmed Al-Saud with achievements and experience
- **📅 Reservation Form** — Interactive booking form with date/time/guest selection
- **⭐ Guest Testimonials** — Customer reviews carousel
- **✨ Animations** — Scroll reveal animations, animated counters, floating particles
- **📱 Fully Responsive** — Mobile-first, works perfectly on all devices
- **🎨 Luxury Design** — Gold & dark theme inspired by Saudi Arabian heritage

```
├── css/
│   └── style.css       # All styles (dark theme, responsive, RTL)
├── js/

```

## 🔧 Setup

Clone and open `index.html` in any browser:

```bash
git clone git@github.com:arabixweb/kingdom-grill.git
cd kingdom-grill
```

No build tools required — pure vanilla HTML/CSS/JS.
